# Análise de Churn de Clientes

[🇬🇧 English](README.md) | 🇧🇷 Português

## Descrição

Este projeto realiza uma análise completa de churn (abandono) de clientes utilizando Python. Inclui limpeza de dados, análise exploratória e visualizações interativas.

**Ferramentas principais:** `pandas` + `plotly`

## 📋 O que está incluído

- **Limpeza de Dados**: Processamento e preparação dos dados brutos
- **Análise Exploratória**: Investigação das características e padrões dos dados
- **Visualizações**: Gráficos interativos para melhor compreensão dos resultados

## 🚀 Como começar

### Pré-requisitos

- Python 3.7+
- pip ou conda

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/rickrodrigues2026/customer-churn-analysis.git
cd customer-churn-analysis
```

2. Instale as dependências:
```bash
pip install -r requirements.txt
```

### Executando a análise

Abra e execute os notebooks Jupyter:

```bash
jupyter notebook
```

Os notebooks contêm toda a análise passo a passo com explicações detalhadas.

## 📚 Notebook Principal

O notebook principal contém:

1. **Carregamento dos Dados**: Importação e visualização inicial
2. **Limpeza de Dados**: Tratamento de valores ausentes, outliers e normalização
3. **Análise Exploratória**: Estatísticas descritivas e distribuições
4. **Visualizações Interativas**: Gráficos com plotly para exploração dos dados
5. **Insights e Conclusões**: Padrões e tendências identificadas

## 🛠️ Dependências

- **pandas**: Manipulação e análise de dados
- **plotly**: Visualizações interativas
- **numpy**: Cálculos numéricos
- **scikit-learn** (opcional): Para análises estatísticas avançadas
- **jupyter**: Ambiente de notebook

## 💡 Casos de Uso

Este projeto é útil para:

- Entender padrões de churn de clientes
- Identificar fatores que influenciam o abandono
- Criar visualizações para apresentações
- Aprender técnicas de análise de dados com Python
