# Python Insights: Customer Churn Analysis with Python

## English

Exploratory data analysis project focused on customer churn. The notebooks examine the churn rate, compare customer characteristics, and visualize patterns that may inform retention actions.

### Files

- `inicial.ipynb`: starter notebook for the exercise.
- `gabarito.ipynb`: notebook with the completed analysis.
- `cancelamentos.csv`: dataset used by the notebooks.

### How to run

1. Install Python and Jupyter Notebook, or Visual Studio Code with the Jupyter extension.
2. Install the dependencies: `pip install pandas plotly nbformat ipykernel`.
3. Keep `cancelamentos.csv` in the same folder as `gabarito.ipynb`.
4. Open the notebook and run the cells in order, from top to bottom.

The original course data files are also available [at this link](https://drive.google.com/drive/folders/1uDesZePdkhiraJmiyeZ-w5tfc8XsNYFZ?usp=drive_link).

## Português

Projeto de análise exploratória de dados de cancelamento de clientes. Os notebooks investigam a taxa de cancelamento, comparam características dos clientes e apresentam padrões que podem apoiar ações de retenção.

### Arquivos

- `inicial.ipynb`: notebook inicial do exercício.
- `gabarito.ipynb`: notebook com a análise resolvida.
- `cancelamentos.csv`: base de dados usada pelos notebooks.

### Como executar

1. Instale Python e Jupyter Notebook ou Visual Studio Code com a extensão Jupyter.
2. Instale as dependências: `pip install pandas plotly nbformat ipykernel`.
3. Mantenha `cancelamentos.csv` na mesma pasta de `gabarito.ipynb`.
4. Abra o notebook e execute as células em ordem, de cima para baixo.

Os arquivos de dados originais do curso também estão disponíveis [neste link](https://drive.google.com/drive/folders/1uDesZePdkhiraJmiyeZ-w5tfc8XsNYFZ?usp=drive_link).
